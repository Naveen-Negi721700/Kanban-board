# Kanban Board
A Kanban Board web application built using HTML, CSS, and JavaScript that helps users organize and manage tasks visually. Tasks can be arranged in different columns such as To-Do, In Progress, and Done, providing a clear workflow for tracking progress and improving productivity.

## Technologies Used
- HTML
- CSS
- JavaScript
